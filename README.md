# Container Studio Releases

Notarized DMG releases and Sparkle appcast for Container Studio.

## Download

Latest release: https://github.com/souza-vinicius/container-studio-releases/releases/latest

## Install

### DMG
1. Download the DMG from the latest release
2. Open and drag Container Studio to Applications
3. First launch: Gatekeeper verifies the notarized signature

### Homebrew
```bash
brew install --cask container-studio
```
